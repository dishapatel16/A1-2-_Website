## Data Science at the University of Regina

A small static site for the data science program in the Department of Computer Science, Faculty of Science. This is an academic assignment and is not the official University of Regina admissions website.

## Features

-Program Overview: Explore information about the Data Science program.

-Course Checklist: Browse courses and track learning progress.

-Skills Picker: Explore important skills for a career in Data Science.

-Career Sectors: Discover potential career opportunities.

-Search Tools: Find relevant questions and curriculum information quickly.

-Interactive Design: Switch between program and course views within the same page.

## Open the site

-Download or clone this repository.

-Keep index.html and ur-logo.png in the same folder.

-Open index.html in any modern web browser.

No additional software or installation is required.

## Project Purpose

This website was created as part of an academic assignment to present Data Science program information in a clear, accessible, and engaging format.

## Disclaimer

Program details are provided for educational purposes. Please consult the official University of Regina website for the latest course, admission, and degree requirements.
