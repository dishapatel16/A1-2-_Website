# Data Science at the University of Regina

A small static site for the data science program in the Department of Computer Science, Faculty of Science. It is not the official admissions site.

## Open the site

Open `index.html` in a browser. Keep `ur-logo.png` in the same folder. Nothing else is required.

- Program is the page that opens first.
- Courses is the course checklist.
Both views are in `index.html`.

The program switcher, course list, skills picker, career sectors, question search, and curriculum search all run inside that file.
